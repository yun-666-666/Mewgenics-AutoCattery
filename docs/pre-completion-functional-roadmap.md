# AutoCattery 当前功能与后续路线

更新日期：2026-08-30

当前公开版本 v0.5.24 已完成玩家测试。本文只保留当前能力和真正尚未进入的未来
功能，不再重复旧版本的逐次故障与修复记录。

## 已完成并通过玩家测试

- House 两个普通按钮、F10 设置/保护/完整预览和中英文界面。
- 当前 build 限定的两次点击 MoveOnly。
- 2、3、4 房人数与用途分配。
- 当前运行时 CatId/房间刷新、房外猫处理和批次间重新规划。
- 预览后状态变化取消、保存退出重进和重复执行幂等。
- 战斗推荐、猫详情和升级重骰配置。
- 稳定身份保护、禁止移动、固定房间和规则移除。
- 分阶段繁育评分与全房异性交叉稳健组合池。
- 备份、离线恢复和测试副本工具。

## 当前能力边界

- 自动整理只执行房间移动，不执行真实淘汰。
- 不自动组建出征队伍。
- 不自动休息、推进天数或选择出征。
- 未确认的游戏字段、硬容量和未来 build 偏移不会被猜测为事实。

## 暂缓

- 多日繁育优化需要更多玩家游戏日才能判断长期收益；当前没有足够新数据，暂不
  调整技能、被动或变异权重。
- 历史版本问题在当前版本没有重现，不作为待办继续调查。

## 未来功能候选

以下内容只在用户明确提出后启动，不是当前缺陷：

1. 真实淘汰、明确确认、journal、部分失败处理和撤销。
2. 新游戏 build 或新原生字段的兼容适配。
3. 基于更多长期数据的繁育权重调整。
4. 用户提出的其他玩家可见功能。

开始未来功能前继续遵守：当前代码和玩家结果优先、最小实现、构建测试与玩家验收
分开、不得启动或控制 Mewgenics。
