# AutoCattery v0.5.10

- 修复 F10 设置的升级重骰次数被后加载 Mewtator 数据 MOD 覆盖的问题。
  AutoCattery 现在会在部署和保存重骰设置时去重并移动到 `modlist.txt` 末尾；
  最终重骰次数以 F10 设置为准，不额外叠加其他 MOD 的同类数值。
- 修复 F10 关闭后重新扫描、注册 House 按钮所触发的过期 UI 根访问风险。
  F10 打开时只临时隐藏和禁用按钮，关闭后直接恢复原挂载。
- 保留 v0.5.9 的房间用途规则：只有已确认的繁育配对房考虑性别，战斗房和
  普通房不会为了公母比例移动猫。

需要重启游戏才能应用重骰数据。请通过 Mewtator 启动游戏。
