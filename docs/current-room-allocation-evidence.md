# 当前房间分配证据与取舍

更新日期：2026-08-07

本文记录 `current-build-purpose-aware-room-planning-v8` 的事实边界。外部研究报告和
`All7Cat_ManualRoomAllocator` 只作为候选设计，不作为游戏字段、阈值或 API
的权威来源。

## 证据优先级

1. 当前仓库代码和当前 build 适配器。
2. 最新运行日志与玩家实机结果。
3. 当前存档的只读解析结果。
4. 可追溯的公开机制资料。
5. 用户提供的研究报告和算法骨架。

本轮公开教程、逆向资料、置信度和自动化映射汇总见
[`mewgenics-breeding-automation-research.md`](mewgenics-breeding-automation-research.md)。

## 当前已确认

- 自动整理只由 House 按钮触发；不绑定每日、读档或结束一天事件。
- 当前 build 已验证普通房间 ID 为 `Attic`、`Floor1_Large`、
  `Floor1_Small`、`Floor2_Large`。
- 当前原生移动函数可移动猫并独立读回目标房间；8 猫与 25 猫两房存档已
  通过玩家验证。
- 存档能读取当前 House CatId、房间成员、七项属性和当前样本的公母。
- 公开 House 机制资料称：每个房间超过 4 只猫后，每多一只会使舒适度减
  1；这是一项属性惩罚，不是已证实的硬容量。
- Appeal 是全屋属性；Comfort、Stimulation、Health、Mutation 是房间属性。
- 当前存档 `furniture` 表已确认保存家具 ID 和所属房间；当前安装包的
  `resources.gpak/data/furniture_effects.gon` 保存家具的实际属性值。
- 主存档第 263 天实读：88 只 House 猫；`Attic` 舒适 11、刺激 41；
  `Floor1_Large` 舒适 -2、刺激 15、变异 20；`Floor1_Small` 舒适 6；
  `Floor2_Large` 舒适 -1、刺激 9。
- 25 猫三房档实读：只有 `Floor1_Large` 有非零培养属性（舒适 8、刺激 4、
  健康 2、变异 1），其余两房为 0。
- 公开 House 资料称亲缘、性向和 libido 等查看能力随 Tink 奖励解锁，不能
  假设所有进度都能读取。

## 当前拒绝或保持未知

- 不把 `default_soft_capacity=4` 当作游戏硬容量。
- 不使用文档给出的固定 A-E 房间用途。
- 不使用未验证的舒适、刺激、健康、变异阈值和角色权重。
- 不使用当前存档尚未可靠提供的亲缘、性向、libido 或家具阻止繁育状态。
- 不实现每日自动运行、强制繁殖、结束一天、直接生成猫、自动放生或删除。
- 不声称当前分配已经锁定实际配对或保证繁殖结果。

## 本轮已实现

- 对当前实际识别的 2、3、4 房计算均衡人数，目标人数最大相差 1；固定居民
  以后接回时可作为下限。
- 只有存在已确认的一公一母推荐繁育对时，才对独立繁育目标房按全屋可用公母
  建立最佳可达的基本均衡；战斗、训练和普通房完全忽略性别。
- 人数仍保持最大相差 1；出现余数时，比较入住后舒适度并由实际属性决定
  哪个房间多一只，而不是固定房间顺序或沿用当前摆放。
- 繁育房先应用已确认的舒适 `≤ -10` 自动失败边界，再同时比较舒适与刺激的
  短板；不再因单项刺激极高而选择低舒适房。
- 战斗推荐猫进入高健康、高舒适的安全驻留房，不默认启用存在受伤、死亡风险的
  低舒适 Fight Club，也不再占用最高刺激房。
- 开启幼猫分离且存在额外可用房时，幼猫进入高健康、高舒适育幼目标；固定与
  不可移动居民仍优先，不把 Appeal 误当房间属性。
- 具体猫的目标由潜力/战斗评分、房间用途和稳定 CatId 决定，不再以当前位置
  作为最少移动成本；人数相同但手动换猫也会恢复属性目标。
- 推荐繁育对之外的繁育房槽位按现有合格配对排序贪心选择不重复配对；排序只
  使用已验证的七维覆盖、性向和后代 COI。它优化同房候选池，不声称锁定实际配对。
- 原生移动按每批最多 8 只执行；批次之间跨 UI tick 刷新运行时快照并重新规划，
  离开 House 或 generation 改变会停止后续批次。
- 未知容量不产生淘汰建议，真实淘汰继续禁用；原生移动门仍负责最终拒绝。

## 尚未实现

- 在 House UI 中直接显示读取到的房间属性和逐猫目标原因。
- 多繁育房手动用途配置、libido 和家具阻止繁育状态的可靠适配。
- 稳定全 7 特征评分使用最终选定繁育房的实际刺激值；当前评分仍使用全屋最高
  刺激，不能把它解释为已经绑定最终房间。
- 4 房主存档的分批执行、繁育组合池结果、预览后手动移动失效复测和游戏保存后
  持久化验证。
