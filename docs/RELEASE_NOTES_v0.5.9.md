# AutoCattery v0.5.9

## Purpose-aware sex allocation

- Removes the automatic one-female/one-male requirement from every room.
- Sex constraints now apply only to the confirmed recommended breeding pair.
- Uses a breeding-pair room separate from the best combat-development room
  when multiple rooms are available.
- Combat and ordinary rooms no longer move cats merely to improve their sex
  ratio.
- When no reliable breeding pair is available, sex does not trigger moves.

Room population balancing, protection rules, MoveOnly execution, combat
recommendations, and player configuration remain unchanged.
