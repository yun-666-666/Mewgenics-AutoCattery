# AutoCattery v0.5.2

## What changed

- Removed the trash-can artwork from the House **Auto-Organize Cattery** and
  **Mark Combat Cats** buttons.
- Centered both button labels after removing the icon space, including their
  normal and pressed states.
- Kept the bilingual prerequisite installation guide, official Mewjector and
  Mewtator links, and the explicit `Mewtator/mods/AutoCattery` destination.
- Runtime planning and movement behavior are unchanged from v0.5.1.

## Installation reminder

Use `AutoCattery-v0.5.2-Windows-x64.zip` for installation. Install
[Mewjector](https://github.com/githubuser508/mewjector) and
[Mewtator](https://github.com/dancomstock/mewtator) first, then copy the package's
`Mewjector/mods` contents to the game's `mods` folder and copy
`Mewtator/AutoCattery` into `Mewtator/mods`, producing
`Mewtator/mods/AutoCattery`. Add `AutoCattery` to `Mewtator/mods/modlist.txt` and
launch the game through Mewtator.
