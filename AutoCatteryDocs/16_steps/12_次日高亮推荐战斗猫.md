# 第 12 阶段：次日高亮推荐战斗猫

## 文档定位

实现第二天按钮：在 House 挑猫、装入出征盒子的阶段点击后，明显标记高
评分战斗猫，不自动组队、不自动选择。

> 当前 build 的玩家实机修正：点击游戏原生 `出发!` 后进入的
> `ClassChooser` 只能查看已放入盒子的猫，不能选择或更换猫。因此本阶段
> 的推荐与高亮主入口必须在 House，不能把 ClassChooser 当作选猫界面。

## 固定技术基线

- 主路线：Windows x64 原生 DLL MOD。
- 运行时加载器：**Mewjector**。
- 游戏内 UI：**MewUI API**，以源码依赖方式编译进本 MOD。
- 可选安装管理器：Mewtator，仅用于安装和启停，不属于硬依赖。
- 参考实现：
  - Quick-Cleanup：参考“家园场景注入按钮并触发一次性操作”。
  - Mewgenics Breeding Manager：参考猫评分、血缘/近亲检查、房间优化、文件竞态处理；只能复用许可证允许的代码。
  - Online Savegame Editor：参考 `.sav` 解析、SQLite/LZ4、dirty tracking、备份和安全写回。
  - Mewgenics QoL Manager：仅参考批量筛选、房间移动、符号标记的交互思路。
  - MewgenicsModTool：仅作为“实时读取、推荐、cull 可行”的能力证据；未获许可时不得复制代码或资源。
- 不采用“自动组队策略”。战斗猫只按独立评分排序和标记，不分析职业搭配、站位或队伍协同。
- 两个主动按钮：
  1. 家园界面：`自动整理猫舍`。只有玩家点击后才分析、分类、淘汰和调整房间。
  2. 次日 House 挑猫/装盒阶段：`标记推荐战斗猫`。点击后只高亮高评分
     猫，不自动放入盒子或自动选队。

## 业务规则

1. 整理完成时保存推荐快照。
2. 玩家手动休息。
3. 次日在 House、尚可挑猫并放入出征盒子时。
4. 玩家点击 `标记推荐战斗猫`。
5. MOD 验证快照并高亮推荐猫。
6. 再次点击清除标记。

## 快照有效性

优先使用上一日整理结果，但需验证：

- `current_day == created_on_game_day + 1`。
- 推荐猫 ID 仍存在。
- 猫仍可出战。
- 评分配置未变。
- 游戏 build 兼容。

如果只部分失效：

- 重新读取当前出战候选。
- **只重新计算战斗评分**，不整理房间、不淘汰。
- 显示“已根据当前状态重新计算”。

如果没有历史快照，也允许按钮即时只读评分并标记。

## 目标匹配

通过稳定 CatId 把推荐结果映射到出征界面猫卡/猫实体。不得用名字唯一匹配。映射失败的 ID 记录但不崩溃。

## 标记样式

默认最多标记 8 只，配置可改。按排名区分：

- #1–#3：强脉冲描边 + 大号星标 + 排名与分数。
- 其余推荐：稳定描边 + 星标。
- 低置信度：标记上加 `?` 或“数据不完整”。

提供“色盲友好模式”：除了颜色，还必须有形状和文字。

## UI 操作

按钮第一次点击：

- 加载/重算排名。
- 创建标记。
- 文案变为 `清除推荐标记`。
- 显示摘要：`已标记 8 只高评分战斗猫`。

第二次点击清除。翻页/筛选/滚动时标记控制器监听卡片复用事件并重新绑定，不能把上一只猫的标记留给新卡片。

## 不自动组队的硬限制

代码层禁止调用任何选择、确认出战、队伍槽位写入接口。为防回归，给 UI 适配器拆出只读映射接口：

```cpp
class IEmbarkUiAdapter {
public:
    virtual Result<std::vector<EmbarkCatView>> EnumerateCatViews() = 0;
    virtual Result<void> AddRecommendationVisual(const EmbarkCatView&, const MarkerSpec&) = 0;
    virtual Result<void> RemoveRecommendationVisual(CatId) = 0;
};
```

该接口中不存在 `SelectCat()`。

## 配置

```json
{
  "recommendation_marker": {
    "recommended_count": 8,
    "show_score": true,
    "show_rank": true,
    "pulse_top_n": 3,
    "auto_clear_on_scene_exit": true,
    "recompute_if_stale": true,
    "never_auto_select": true
  }
}
```

`never_auto_select` 为只读常量或 schema 中不可关闭的安全声明，不提供 false。

## 测试

- 正常 Day N 整理、Day N+1 标记。
- Day N+2 才打开，触发重算或过期提示。
- 推荐猫死亡/不可用/不存在。
- UI 虚拟列表复用。
- 重复点击开关。
- 无历史快照。
- 评分配置变化。
- 确认任何情况下选队状态均不改变。

## 验收标准

- 标记足够明显且可清除。
- 只标记独立高评分猫。
- 不自动选择或组队。
- 无快照时也能只读重算。
- 场景退出无残留。
