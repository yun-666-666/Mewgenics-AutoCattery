# 第 08 阶段：保护规则、锁定、白名单与黑名单

## 文档定位

为自动整理建立不可绕过的保护层，防止收藏猫、手动锁定猫或特殊猫被移动/淘汰。

## 固定技术基线

- 主路线：Windows x64 原生 DLL MOD。
- 运行时加载器：**Mewjector**。
- 游戏内 UI：**MewUI API**，以源码依赖方式编译进本 MOD。
- 可选安装管理器：Mewtator，仅用于安装和启停，不属于硬依赖。
- 参考实现：
  - Quick-Cleanup：参考“家园场景注入按钮并触发一次性操作”。
  - Mewgenics Breeding Manager：参考猫评分、血缘/近亲检查、房间优化、文件竞态处理；只能复用许可证允许的代码。
  - Online Savegame Editor：参考 `.sav` 解析、SQLite/LZ4、dirty tracking、备份和安全写回。
  - Mewgenics QoL Manager：仅参考批量筛选、房间移动、符号标记的交互思路。
  - MewgenicsModTool：仅作为“实时读取、推荐、cull 可行”的能力证据；未获许可时不得复制代码或资源。
- 不采用“自动组队策略”。战斗猫只按独立评分排序和标记，不分析职业搭配、站位或队伍协同。
- 两个主动按钮：
  1. 家园界面：`自动整理猫舍`。只有玩家点击后才分析、分类、淘汰和调整房间。
  2. 次日出征/选猫界面：`标记推荐战斗猫`。点击后只高亮高评分猫，不自动选队。

## 保护优先级

保护规则必须在评分之后、任何规划和执行之前再次检查。保护优先于所有自动化规则。

保护来源：

1. 游戏原生锁定/收藏标志。
2. MOD 侧永久白名单。
3. MOD 侧“禁止淘汰但允许移动”。
4. MOD 侧“完全不管理”。
5. 未识别稀有突变/特殊状态的保守保护。
6. 当前任务、剧情、访客、临时实体保护。

## 保护级别

```cpp
enum class ProtectionLevel {
    None,
    NoCull,
    NoMove,
    NoCullOrMove,
    FullyUnmanaged
};

struct ProtectionRecord {
    CatId cat_id;
    ProtectionLevel level;
    std::string source;
    std::string reason;
    std::optional<int> expires_on_day;
};
```

`FullyUnmanaged` 的猫仍可出现在分析列表中，但不参与自动房间调整和淘汰。

## Sidecar 文件

不依赖修改猫名。保存到 MOD 数据目录：

```json
{
  "schema_version": 1,
  "cats": {
    "12345": {
      "level": "NoCullOrMove",
      "reason": "收藏血统",
      "added_at": "2026-07-28T00:00:00Z"
    }
  },
  "rules": {
    "protect_game_favorites": true,
    "protect_game_locked": true,
    "protect_unknown_special_state": true,
    "protect_unknown_mutations": true
  }
}
```

写入采用临时文件 + fsync/flush + 原子重命名。损坏时加载最近备份并进入只读。

## 黑名单的安全定义

可以提供“优先淘汰名单”，但它不能绕过硬保护，也不能让不合格状态猫直接被删除。黑名单只是给候选排序加权：

```text
Protected > Safety Eligibility > Minimum Pools > Blacklist Preference
```

## UI 管理

本阶段可增加调试/设置面板：

- 搜索猫 ID/名字。
- 设置保护级别。
- 显示保护来源。
- 导入/导出保护 sidecar。
- 清除过期临时保护。

不必在主家园界面放复杂设置；可使用独立设置页或配置文件。

## 双重校验

规划时生成 `ProtectionDigest`；执行前重新读取保护状态。若两次摘要不同，整次执行取消并要求重新预览。

```cpp
struct ProtectionDigest {
    std::string sha256;
    size_t protected_count;
};
```

## 边界情况

- 猫被玩家在预览后手动锁定：执行必须取消或跳过该猫。
- 稳定 ID 被复用：如果名字/出生信息等指纹明显变化，sidecar 记录进入冲突状态，不自动应用旧保护。
- 用户删除 sidecar：只恢复游戏原生保护，不推测旧数据。
- 未知游戏 build：自动启用“未知特殊状态保护”。

## 测试

- 所有保护级别。
- sidecar 损坏、空文件、旧 schema、新 schema。
- 同时白名单和黑名单，白名单获胜。
- 预览后保护变化。
- 1000 条记录加载性能。

## 验收标准

- 任何保护猫都不会进入实际淘汰列表。
- `NoMove` 猫房间不变。
- `NoCull` 猫可参与安全移动，但不可淘汰。
- 保护文件损坏时自动禁用破坏性操作。
