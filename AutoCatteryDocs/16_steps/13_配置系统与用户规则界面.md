# 第 13 阶段：完整配置系统、热加载与用户规则界面

## 文档定位

把评分、保留数量、房间策略、安全选项和视觉标记做成可验证配置，并提供简洁设置入口。


## 给 Codex 的通用执行规则

1. **只实施本文档对应的阶段**，不得提前实现后续阶段，也不得把多个阶段合并为一次大改动。
2. 开始前先检查当前仓库实际状态、已有提交、构建方式和本阶段依赖是否已完成；已有实现优先复用，不重复造轮子。
3. 不进行新的联网研究，不搜索新的 MOD，不擅自改换技术路线。本文档中的外部项目只作为既定参考基线。
4. 不修改游戏原始文件，不提交游戏二进制、反编译产物、个人存档、第三方闭源资产或未经许可的代码。
5. 每个阶段都必须：先读取相关文件 → 做最小修改 → 构建/测试 → 记录结果 → 创建一个本地 Git commit。**绝不自动 push 到 GitHub。**
6. 遇到未知的游戏函数、结构体偏移、场景名或 UI 节点名时，不得编造。应增加探针、日志、适配接口或安全失败路径，并把待确认项写入阶段报告。
7. 任何会移动、淘汰或写入猫数据的功能，默认必须可预览、可取消、可回滚；无法确认安全时只能进入只读模式。
8. 本阶段验收未通过时停止，不继续下一阶段。输出实际改动文件、测试结果、剩余风险和本地 commit 哈希。


## 固定技术基线

- 主路线：Windows x64 原生 DLL MOD。
- 运行时加载器：**Mewjector**。
- 游戏内 UI：**MewUI API**，以源码依赖方式编译进本 MOD。
- 可选安装管理器：Mewtator，仅用于安装和启停，不属于硬依赖。
- 参考实现：
  - Quick-Cleanup：参考“家园场景注入按钮并触发一次性操作”。
  - Mewgenics Breeding Manager：参考猫评分、血缘/近亲检查、房间优化、文件竞态处理；只能复用许可证允许的代码。
  - Online Savegame Editor：参考 `.sav` 解析、SQLite/LZ4、dirty tracking、备份和安全写回。
  - Mewgenics QoL Manager：仅参考批量筛选、房间移动、符号标记的交互思路。
  - MewgenicsModTool：仅作为“实时读取、推荐、cull 可行”的能力证据；未获许可时不得复制代码或资源。
- 不采用“自动组队策略”。战斗猫只按独立评分排序和标记，不分析职业搭配、站位或队伍协同。
- 两个主动按钮：
  1. 家园界面：`自动整理猫舍`。只有玩家点击后才分析、分类、淘汰和调整房间。
  2. 次日出征/选猫界面：`标记推荐战斗猫`。点击后只高亮高评分猫，不自动选队。

## 配置分层

1. 编译内置安全默认值。
2. `default_config.json`：随 MOD 发布。
3. `user_config.json`：用户覆盖。
4. 临时运行时设置：仅本次游戏会话。

安全默认值不能被缺失或损坏配置关闭。

## Schema 模块

完整配置至少分：

- `general`
- `combat_scoring`
- `breeding_scoring`
- `classification`
- `protection`
- `room_planning`
- `execution_safety`
- `recommendation_marker`
- `diagnostics`

每个模块有独立 `version`，总 schema 也有版本。

## 验证规则

- 推荐数量 1–100。
- 权重必须有限数，限制合理范围。
- 软容量 >= 1。
- 最大溢出 >= 0。
- 最低保留池不得为负。
- `never_auto_select` 固定 true。
- 关闭备份时自动禁止淘汰，而不是允许无备份淘汰。
- 未知枚举值报错并使用安全默认值。

## 热加载

只允许在工作流 Idle 时热加载。加载后：

- 计算新 config hash。
- 评分和推荐缓存失效。
- 当前已显示标记提示需要重算。
- 不自动运行整理。

文件监听要去抖；写一半的文件不能被加载。先读取、解析、验证到新对象，再原子替换当前配置。

## 用户界面

设置入口可放在 MOD 调试/设置面板，不挤占家园主 UI。推荐分三页：

1. 简单：推荐数量、是否排除受伤、最低保留数、是否允许软溢出。
2. 高级：详细权重和覆盖表。
3. 安全：预览、备份、单击模式、只读模式、恢复目录。

所有破坏性相关开关带说明。开启单击模式前要求明确确认。

## 预设

提供：

- `保守`：保留更多猫、无自动淘汰或高阈值。
- `平衡`：默认。
- `激进`：更少保留，但仍不能绕过保护和备份。

预设只是填充值，不改变硬安全约束。

## 配置迁移

```cpp
class ConfigMigrator {
public:
    Result<Json> Migrate(Json input, int from_version, int to_version);
};
```

迁移前备份旧配置；迁移失败使用默认值并保留原文件。

## 导入导出

允许导出配置和评分规则，不包含个人猫 ID 保护表，除非用户单独选择导出保护数据。

## 测试

- 每个字段边界。
- 非法 JSON、截断文件、NaN 字符串、超大数组。
- 热加载发生在评分/执行期间，应延迟。
- 旧版本迁移。
- 安全约束不可被配置绕过。

## 验收标准

- 用户可调整推荐猫数量和评分权重。
- 修改配置不会自动整理。
- 无效配置安全回退并给出具体错误位置。
- 设置界面不影响游戏原 UI。
