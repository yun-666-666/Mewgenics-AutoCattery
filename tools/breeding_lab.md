# 游戏外繁育实验：已确认的七项遗传属性链

这次从本机游戏 EXE 定位并复现了 `CatData::breed` 中的七项遗传属性生成，
不是用 AutoCattery 配对评分代替游戏算法。脚本不启动游戏、不读取或改写存档。
**完整新生猫生成器尚未完成**：这里输出的是遗传步骤的七项基础值，不是包含
身体部件、突变、技能、被动等修正后的详情面板，也不是每天的实际出生率。

## 运行

普通实验仅使用 Python 标准库。父母参数应为相同顺序的七项**遗传基础属性**，
不能混入升级、装备或其他加成。示例全部是构造数据，不是针对个人存档调参。

在仓库根目录的 PowerShell 中运行：

```powershell
python tools/breeding_lab.py --mother 7 1 7 1 7 1 7 --father 1 7 1 7 1 7 1 --samples 100000
python tools/breeding_lab.py --mother 7 1 7 1 7 1 7 --father 1 7 1 7 1 7 1 --samples 100000 --effects '{"Stimulation":20}'
```

输出 JSON 包含单项分布、期望属性、七项同时达到 `--threshold` 的模型概率、
实际模拟次数和命中数，以及前五个后代的遗传属性。默认门槛是 7。
`--state` 接受四个 64 位无符号整数，可用 `0x` 前缀；它是**进入遗传步骤时**的
随机状态，不是存档种子。默认状态是人为选取的可复现实验输入。
没有复现整次出生在此步骤之前消耗的随机数，不能据此预测存档的下一只猫。

`--effects` 接受游戏已经算出的有效效果数值，不是家具数量或未处理的房间面板值。
目前支持 `InheritStatFavorMom`、`InheritStatFavorDad`、`InheritStatFavorBest`、
`Stimulation`。尚未接入家具配置、稀有效果及房间运行状态的求值链。

## 原生证据

下表地址均为 **2026-09-13 本机受检 EXE 的 RVA**，不承诺其他版本相同。
EXE 的 Windows FileVersion/ProductVersion 为空，因此未凭空标注构建版本。
仓库不携带 EXE、反汇编文件或游戏资源。更新游戏后必须重新定位相关代码。

| `0xA7A00` | 单项双亲取值选择及权重归一化 |

breed 先调用初始化函数 `0xB7320`，随后这七项被双亲选择结果覆盖。
脚本原生校验从七项选择区段入口执行到 `0xA8FA0`，包括原始 helper 和 RNG。
初始化产生的其他字段，以及后续技能、被动、身体与缺陷逻辑没有被伪造为已复现。
另一个调用属性随机增减的函数 `0xAA1E0`，当前找到的调用点位于创建随机猫的路径；
没有把它未经证实地套到每只繁育后代身上。

## 已复现的规则

三种初始权重来自 breed 的初始化及原生家具求值器：

```text
M = 1 + 0.25 * InheritStatFavorMom
D = 1 + 0.25 * InheritStatFavorDad
B = 0.10 * InheritStatFavorBest + 0.01 * Stimulation
```

逐项处理：

- 母方较高且 B > 0：M 增加 B；若 B <= 0，则 D 减去 B。
- 父方较高且 B > 0：D 增加 B；若 B <= 0，则 M 减去 B。
- 两者相等：不增加偏好权重。
- 选择母方的概率为 `M / (M + D)`；结果越界或 NaN 时原生回退到 0.5。
- 概率为 0 或 1 时不消耗随机数；否则比较 `概率 > 随机值`。
- 即使双亲属性相同，只要概率在 0 和 1 之间，原生仍消耗一次随机数。

因此这个步骤逐项选取双亲的值，不取平均，也不自行加减属性。B 是权重，
不是直接增加若干百分点。例如有效 Stimulation=20、无其他效果、双亲该项不等时，
较高值被选中的概率为 `1.2 / 2.2`，不是 70%。

七项同时达标的解析值是各项概率乘积，采用均匀独立随机抽样的概率模型。
实际脚本使用移植的游戏 PRNG 进行有限次抽样，统计结果有抽样误差。
这些概率均以已进入该后代的遗传步骤为条件，不能乘猫数就当作每天产量。

## 原始指令对照测试

原生参考仅在 Unicorn 的独立模拟内存中映射本地 EXE，提供父母属性、权重、
TLS 随机状态及栈。它不向游戏进程注入代码，不执行游戏入口，不修改 EXE。
没有用 Python 替换被测的遗传选择、随机数或家具效果计算。

需要 `pefile`、`unicorn`（本次安装 unicorn 2.1.4，pefile 已存在）：

```powershell
python tests/breeding_lab_tests.py --exe ..\Mewgenics.exe
```

2026-09-13 实际结果：1,080 组七属性与随机最终状态完全一致，24 项原生家具
效果计算一致。包括正负偏好、相等属性、0/1 概率不消耗 RNG、非法归一化的
原生回退分支。附带全 7、无法达到 7、恰好互补分布检查通过。

使用脚本默认随机状态，每组 100,000 次：

| 构造场景 | 全七项至少 7 的条件概率 | 实际命中 |
| --- | ---: | ---: |
| 七项恰好互补，无效果 | 0.78125% | 759 / 100000 |
| 同一对父母，有效 Stimulation=20 | 1.43651430985% | 1392 / 100000 |
| 三项共同为 7、其余四项互补，无效果 | 6.25% | 6140 / 100000 |

实际房间及家具转换为有效效果的规则。当前未修改 MOD 的推荐算法。
