02　培养设置

每天重新选择种猫与分房。舒适、健康等房屋效果使用真实数值。

超过上限时保留兼容种猫对、优秀战斗猫，再按遗传质量择优；淘汰记录单独列出，祖先谱系保留。

默认 0：只使用真实库存及家具供食。大于 0 表示你计划每天补充的数量，模拟不会替游戏补食。

房间不足时，多对种猫会共用繁育房；实际安排数取决于当前合格种猫数量。进展会显示实际安排 / 目标，不保证每对每天都生育。

使用存档副本模拟，不会修改正在玩的原存档。可在完整模拟日结束时取消。
